# Phase 4 — package removal candidates
# Generated 2026-09-10, after ML4W 2.15.1 install.
#
# State at generation: 241 explicit / 1433 total installed, 32 orphans.
#
# MECHANISM CHANGE from the original design: the spec called for marking
# everything --asdeps, pinning a keep-list, then sweeping orphans. ML4W now
# owns ~100 explicit packages, so that approach would require enumerating its
# entire dependency set perfectly — one miss breaks the fresh install. This is
# an explicit remove-list instead: name what goes, then sweep only what those
# leave orphaned. A mistake costs one package, not the desktop.
#
# Every group below was checked with `pactree -r` for reverse dependencies.
# Groups are applied individually so any one can be skipped.
#
# ══════════════════════════════════════════════════════════════════════
# DECISIONS — 2026-09-10. Executed by phase4-purge.sh.
#
#   REMOVE  safe-cruft, wrong-hardware, xorg-leftovers   (~2.6 GiB)
#   REMOVE  ollama, virtualbox                           (~296 MiB)
#   KEEP    dev-infra      — work toolchain
#   KEEP    heavy-apps     — evidence of active use: 12 .tex files and
#                            pdflatex for texlive, 15 office documents for
#                            libreoffice, ~/Android at 8.2 GiB for
#                            android-studio, a 381 MiB wine prefix
#   KEEP    extra-browsers, ai-editors, spotify-stack
#   KEEP    nvidia-stack   — required for the Hybrid switch below
#
# GPU: switching Integrated -> Hybrid. Integrated removes the dGPU from
# the PCI bus, so it cannot wake on demand; Hybrid keeps it present and
# runtime-suspended, reachable through prime-run. This gives back some of
# the June battery saving — measure with measure-battery.sh on battery,
# under the same power profile, before and after.
#
# Net effect: ~2.9 GiB, not the wholesale reset originally scoped. The
# "no previous packages" goal was deliberately traded away in favour of
# keeping a working toolchain.
#
# CAVEAT on the usage evidence: ML4W installed localsearch (a file
# indexer) as a nautilus dependency, and the filesystem mounts relatime,
# so access times are unreliable. The file counts are the sound signal;
# atimes are not.
# ══════════════════════════════════════════════════════════════════════
